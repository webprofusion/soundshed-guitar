Signal Path

Click a node to edit its parameters, drag it to reorder the chain. A bypassed node is dimmed and outlined but stays in the preset and is saved with it; deleting is what takes it out. The handle under the chain switches between the full and icon-only views — drag it, or double-click for full.

Presets and Scenes

Scenes are variations stored inside one preset, so switching between them does not reload the preset. Add to Mixer runs two or more presets at once; saving from the mixer toolbar stores that combination as a Multi-Rig preset.

Jam

Backing tracks search YouTube and play in a floating window that stays open across the rest of the app. Riff captures are written as measure-aligned DI WAV takes, with the tempo, time signature, beat pattern and preset context stored alongside the audio.

Library and Sharing

Tone3000 results come through the Soundshed API by default; browsing your own favourites needs your own Tone3000 key, set under Settings. Published presets are Creative Commons CC0 and go through approval before Share appears on the card.

Performance and Diagnostics

DSP Load measures the single audio thread against its block deadline, not the whole CPU, so it can sit near 100% while the machine reports a low overall load. In the per-node readouts a blank figure means the node did not run in the last block — bypassed, or fed no signal — rather than a measured zero.
