Processing

Spreads heavy chains (stereo NAM and IR, split chains, several presets at once) over extra helper threads. On by default in the standalone app. Off by default in a DAW, which already shares its tracks across your cores: there the extra threads compete with it and can cause crackles. The standalone app and the plugin keep separate settings, and the plugin's applies to every instance.
Runs NAM amp and effect models on Soundshed's optimised engine, which typically uses a half to a fifth of the CPU of the standard NAM engine for the same sound. Turn it off to compare the two, or if a model behaves differently. Changing it rebuilds the running presets, and in a DAW it applies to every instance.

Anti-alias filter for the NAM resampler. Minimum Phase is the low-latency real-time default; the linear options are phase-linear but add latency. This also applies when oversampling is Off if your sample rate differs from the model's native rate.

Preset Switching

Lets the preset you just left keep ringing out over the new one. Its input fades away, and its delay and reverb state is kept for the selected number of bars before fading out. Bars are counted at the current tempo, and each preset still ringing costs CPU. Switching again may end an older tail sooner.

A centred rig sits 3 dB below its input, so that it keeps its loudness when panned across a stereo output. A mono output, such as a mono DAW track or a single interface output, has nothing to pan across: this brings the rig back to its input level there. Stereo outputs are unchanged. In a DAW it applies to instances you add after turning it on, and saved projects keep the level they were made with.
