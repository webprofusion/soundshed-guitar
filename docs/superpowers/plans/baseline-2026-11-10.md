# Baseline: unmodified fork on Linux

Commit `d4ddc65` (upstream `main` as forked), Ubuntu 24.04, g++ 13.3, CMake 3.28, Release.

```
cmake -S core -B core/build -DCMAKE_BUILD_TYPE=Release -DGUITARFX_CORE_BUILD_TESTS=ON
cmake --build core/build -j 4
cd core/build && ctest -j 4 --output-on-failure
```

`npm ci` was run in `core/ui` first (the UI build is part of the core build).

**Result: 170 of 174 tests pass.** The four failures are in upstream code this work does not
touch, and are the reference every later run is compared with:

| Test | First failing check |
|---|---|
| `BuiltinAmpGlideTests` | "silence did not come out silent, so the two amps' filters differ" |
| `BuiltinAmpLegacyMigrationTests` | "a preset's old amp node is migrated as it loads (Output -15.0 -> 0.4 dB)" |
| `DrivePedalTests` | "Distortion: mono output matches stereo sample for sample, every model" |
| `RotaryVibeEffectTests` | "it runs mono, and the mono path matches the stereo one exactly" |

Three of the four compare two code paths sample for sample, which upstream develops and runs
on MSVC and clang; the cause on g++ was not investigated.

## One deviation from the pinned dependencies

`sqlite.org` was not reachable from the build machine, so the SQLite amalgamation was taken
from the npm package `better-sqlite3@12.4.1` and passed with
`-DFETCHCONTENT_SOURCE_DIR_GUITARFX_SQLITE_SRC=`. It is the same version the project pins
(3.50.4), but it was not verified against the project's SHA-256, and that package carries one
patch of its own. This affects only this machine's build; nothing about it is committed.

## After the Sepia changes

Same machine, same commands, branch `lofi-pack-design`: **175 of 179 tests pass.** The five
added tests (`TapeSaturationEffectTests`, `BitcrusherEffectTests`, `SepiaEffectCatalog`,
`SepiaFactoryPackTests`, `OfflineBrandingTests`) pass, and the four failures are the same four
as above. One existing test, `UiClientTests`, was edited: it expected the word "connection" in
the message for an unanswered request, which now reads "Online services are not available in
Sepia."

Two repository checks fail on the unmodified fork as well and were left alone:
`tools/check-cpp-file-sizes.js` (`core/src/dsp/reverb/VerbalEngine.h` is 814 lines) and
`npm run check:pickup-sensing` (the generated header is reported out of date).
